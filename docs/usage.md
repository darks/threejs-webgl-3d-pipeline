# 使用技能

## 从具体需求开始

在支持技能的 Agent 宿主中发送：

```text
$threejs-webgl-3d-pipeline
制作一个欧美低多边形卡通风的邮电局。
产出放进新的 postal-demo 目录，保留可编辑源码。
支持拖动旋转、滚轮缩放、点击邮筒投信和电报灯互动。
```

换一个主题：

```text
$threejs-webgl-3d-pipeline
制作一个可切换日夜的低多边形街角百货店，提供橱窗近景与街角视角。
目标是桌面和手机浏览器；所有文件放到新的 store-demo 目录。
```

```text
$threejs-webgl-3d-pipeline
制作一个伦敦眼河畔微缩场景，摩天轮缓慢转动，可暂停和恢复。
强调结构层次和清晰的卡通配色；在新的 london-demo 目录交付。
```

这些是使用提示示例，不承诺重现本仓库 Demo 的每个像素。可以补充参考图、尺度、机位、目标设备和性能约束；没有指定的设计选择应在 SPEC 中标为假设。

## 默认交付

- 可运行的 HTML 场景入口、源码和启动说明。
- SPEC、空间蓝图、分工计划和集中化的可调参数。
- overview / closeup / lowangle / wireframe 四视图与版本记录。
- 真实独立 Agent 评审、保留失败结论的迭代记录、`progress.html` 画廊。
- HTML 单页的 GLB 与 OBJ 下载按钮，以及匹配最终版本的导出样例与重载检查。

GLB 默认包含受支持材质与贴图；OBJ 默认是几何格式。网页灯光、后处理和交互不等于可移植模型材质，不承诺导出文件完全复现网页渲染。需要 OBJ 材质时明确要求 OBJ、MTL 和贴图配套打包。

## 修改已有项目

指出工程目录和具体变化：

```text
使用 $threejs-webgl-3d-pipeline 继续 ./postal-demo。
保留现有构图，改善入口台阶的穿插问题，重跑受影响检查。
```

小修复不必重开全部六阶段。受影响的图像、参数和导出证据需要更新，不能将旧截图或分数用于新版本。

## 看懂验收结果

视觉评分只覆盖当前冻结版本的四视图；构建、交互、接触和导出检查有自己的证据。达到迭代预算仍未通过时应保留可运行版本并报告不足，不能降低门槛或丢掉不利评审。

缺少图像生成时可保留明确标记的文字/布局参考；缺少独立会话或浏览器运行能力时，完整管线不能宣称通过。生成目标图的像素尺寸和构图漂移也应按实际结果记录。

## 本仓库示例的定位

三个 Demo 是可体验的场景参考。邮电局提供模块源码和历史规格；其余两个仅有独立 HTML。当前展示文件尚未实现新版默认导出要求，也没有作为本次发布的一部分重新做六阶段独立评分。仓库的冒烟测试用于确认发布后的文件仍能加载和交互。
